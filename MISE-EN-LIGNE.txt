SITE ML RACING TEAM — MISE EN LIGNE (gratuit, ouvert à tous)
==============================================================

Tout se fait avec le compte Gmail de l'association : mlracingteam29@gmail.com

1. METTRE LE SITE EN LIGNE (5 minutes)
   - Décompressez le fichier zip : vous obtenez un dossier "site-ml-racing-team".
   - Allez sur https://app.netlify.com/drop
   - Créez un compte gratuit (bouton "Sign up" > Google > mlracingteam29@gmail.com).
   - Glissez le dossier "site-ml-racing-team" dans la zone de dépôt.
   - Le site est en ligne avec une adresse du type https://xxxx.netlify.app
   - Pour une adresse plus jolie : Site configuration > Change site name > "mlracingteam"
     (=> https://mlracingteam.netlify.app si le nom est libre).

2. LES GAZETTES (Google Drive)
   - Dans Google Drive, créez un dossier "Gazettes ML Racing Team".
   - Clic droit > Partager > Accès général : "Tous les utilisateurs disposant du lien" (Lecteur).
   - Copiez le lien. L'identifiant, c'est la suite de lettres après /folders/
     ex. https://drive.google.com/drive/folders/1AbCdEf123  =>  1AbCdEf123
   - Ouvrez index.html avec le Bloc-notes, cherchez  dossierGazettesDrive: ""
     et collez l'identifiant entre les guillemets.
   - Ensuite, pour publier une gazette : déposez simplement le PDF dans ce dossier Drive.
     Elle apparaît automatiquement sur le site, sans rien modifier.

3. LE CHAT EN DIRECT (tawk.to, gratuit)
   - Créez un compte sur https://www.tawk.to avec mlracingteam29@gmail.com.
   - Administration > Canaux > Widget de chat : copiez l'adresse qui commence par
     https://embed.tawk.to/...  (dans le code fourni, c'est la ligne "s1.src=").
   - Collez-la dans index.html :  tawkTo: "https://embed.tawk.to/....",
   - Installez l'appli tawk.to sur votre téléphone pour répondre aux visiteurs.
   - Facultatif : collez le lien d'invitation d'un groupe WhatsApp dans  groupeWhatsApp: ""
     et le lien de la page Facebook dans  pageFacebook: ""

4. LE FORMULAIRE D'INSCRIPTION (déjà en place : page inscription.html)
   - Les dossiers remplis sont envoyés à mlracingteam29@gmail.com par le service gratuit
     FormSubmit (formsubmit.co), et l'adhérent reçoit automatiquement une copie.
   - À FAIRE UNE SEULE FOIS, après la mise en ligne : remplissez le formulaire vous-même.
     FormSubmit envoie alors un e-mail "Activate Form" à mlracingteam29@gmail.com :
     cliquez sur le bouton d'activation. Les inscriptions arrivent ensuite normalement.
   - Pensez à vérifier le dossier "Spam" la première fois.

5. MODIFIER LES PARTENAIRES (sans toucher au code)
   - Ouvrez : https://github.com/mlracingteam29-code/mlr29/edit/main/partenaires.txt
     (connecté au compte mlracingteam29-code)
   - Un partenaire par ligne, dans l'ordre d'affichage. Ajoutez, renommez ou supprimez une ligne.
   - Cliquez sur "Commit changes..." puis de nouveau "Commit changes".
   - Une fois le site lancé, la modification apparaît en 1 à 2 minutes.

6. AJOUTER LES DATES DE ROULAGE (onglet "Dates roulages")
   - Ouvrez : https://github.com/mlracingteam29-code/mlr29/edit/main/roulages.txt
   - Une date par ligne :  JJ/MM/AAAA | Lieu | Type de roulage | Infos (facultatif)
     ex.  15/03/2027 | Circuit de Guillac | Roulage vitesse | Inscription auprès du bureau
   - Les dates sont triées automatiquement ; les dates passées s'affichent en grisé.
   - "Commit changes..." puis "Commit changes".

7. MODIFIER LES TEXTES DU SITE
   - Ouvrez : https://github.com/mlracingteam29-code/mlr29/edit/main/textes.txt
   - Changez le texte SOUS chaque titre entre crochets, ex. [accueil.texte]
     (ne touchez pas aux titres entre crochets).
   - Paragraphes : séparés par une ligne vide. Listes : "Titre — texte", une ligne par élément.
   - "Commit changes..." puis "Commit changes".

APRÈS CHAQUE MODIFICATION DE index.html
   - Netlify > votre site > Deploys > glissez de nouveau le dossier complet.
   (Inutile pour les gazettes ajoutées dans Drive : elles s'affichent toutes seules.)
