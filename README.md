Site vitrine de l'association moto ML Racing Team : présentation, gazettes, échanges en direct, inscription, partenaires, contact.

- Contact et dossiers : mlracingteam29@gmail.com
- Inscription en ligne : `inscription.html` (envoi par FormSubmit vers mlracingteam29@gmail.com, copie à l'adhérent)
- Réglages (Drive des gazettes, chat tawk.to, WhatsApp) : en haut du script dans `index.html`, bloc `REGLAGES`.
- Statut : **privé, en préparation**. Mise en ligne prévue via GitHub Pages (`main`, dossier racine).
