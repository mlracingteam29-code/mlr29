⚠️ Modifications à envoyer sur GitHub

Vos changements ne sont pas encore en ligne. Pour les publier :

  1. Cliquez sur Tout télécharger (autorisez les téléchargements multiples si le navigateur le demande).
  2. Ouvrez la page d'envoi du dossier « membres » sur GitHub ↗.
  3. Glissez tous les fichiers téléchargés, puis cliquez sur Commit changes.

⚠️ Les noms doivent rester exacts (acces.json, index.bin…). Si votre téléphone les renomme en « acces (1).json », supprimez d'abord les anciens fichiers de vos Téléchargements, ou activez la publication directe (plus bas) pour publier en un clic.

🔗 Publication directe sur le site

Pour publier en un clic (fiches « Nos membres », fichiers membres, accès), enregistrez une fois sur cet appareil une clé d'accès GitHub. Elle reste uniquement dans ce navigateur, jamais sur le site.

Comment créer la clé (2 minutes, une seule fois)
  1. Connecté au compte GitHub mlracingteam29-code, ouvrez la page de création de clé ↗.
  2. Nom : « Site ML Racing Team » · Expiration : 1 an.
  3. Repository access : Only select repositories → mlr29.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Cliquez sur Generate token, copiez la clé (elle commence par github_pat_) et collez-la ci-dessous.
