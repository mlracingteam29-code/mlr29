#
#   Nom : prénom et nom affichés
#   Photo : nom du fichier photo déposé dans le dossier « equipe » (ex. clement.jpg)
#   Moto : la ou les motos (ex. Yamaha R6 2019)
#   Numéro : numéro de course (facultatif)
#   Discipline : séparées par des virgules (ex. Vitesse, Supermotard)
#   Texte : petit texte de présentation (peut continuer sur les lignes suivantes)
#
# Les lignes qui commencent par # sont ignorées. Exemple à copier (sans les #) :
#
# Nom : Clément Merroux
# Photo : clement.jpg
# Moto : Yamaha R6
# Numéro : 29
